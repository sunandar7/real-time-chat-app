# 🚀 Real Time Chatting Fullstack App

A fullstack real-time chatting web application built with React, Node.js, Express, and MongoDB.

## 🛠 Tech Stack

### Frontend
- React (Vite)
- Axios
- Redux

### Backend
- Node.js
- Express
- MongoDB
- Mongoose
- JWT Authentication

---

## 📁 Project Structure
client/ → React frontend
server/ → Node.js backend

---

## ⚙️ Installation

### 1️⃣ Clone repository

```bash
git clone https://github.com/sunandar7/real-time-chat-app.git
cd real-time-chat-app

### 2️⃣ Setup backend
cd backend
npm install

## Create .env file
PORT = 3000
MONGO_DB_STRING = your_mongodb_url
SECRET_KEY = your_secret

## Run backend 
npm run dev

### 3️⃣ Setup Frontend
cd frontend
npm install
npm run dev
